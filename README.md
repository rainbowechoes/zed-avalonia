# Avalonia AXAML for Zed

Zed extension for Avalonia `.axaml` syntax highlighting, completion, and diagnostics. Language features are provided by the [AXSG language server](https://github.com/wieslawsoltes/XamlToCSharpGenerator). An embedded UI preview is not currently included.

The extension lives in [`lsp/zed-avalonia`](lsp/zed-avalonia). See its [README](lsp/zed-avalonia/README.md) for requirements, installation, and language-server behavior.

To test from this checkout, run **Zed: Install Dev Extension** and select the `lsp/zed-avalonia` directory.
